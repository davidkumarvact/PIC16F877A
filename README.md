# PIC16F877A Embedded Systems – Study Repository

This repository contains **PIC16F877A microcontroller programs, experiments, and practice projects** developed as part of embedded systems learning and training.

The examples are intended for **educational and study purposes**, particularly for students and trainees who have joined the embedded systems course at **VACT Technologies Pvt. Ltd.**

---

## 📌 About the Repository

The projects in this repository are based on the **PIC16F877A 8-bit microcontroller** and cover fundamental embedded-system concepts such as:

- GPIO / Digital I/O
- LED and switch interfacing
- Timers and counters
- Interrupts
- ADC
- UART / Serial communication
- EEPROM
- PWM
- LCD interfacing
- Keypad interfacing
- Sensor interfacing
- Peripheral programming
- Embedded C programming
- Microcontroller-based mini projects

The primary purpose of these programs is to understand **microcontroller architecture, peripheral configuration, register-level programming, and embedded C development**.

## ⭐ Note for Learners

If you are using these programs for learning, it is recommended to:

- Read the datasheet before modifying the code.
- Understand the relevant registers before using library functions.
- Test each peripheral independently.
- Use a simulator such as Proteus where appropriate.
- Verify hardware connections before programming the MCU.
- Experiment with the code rather than simply copying it.

**Learn → Modify → Test → Debug → Understand**
